# 🚀 Crazy Colorful Contact Form

A modern, highly responsive, and vibrant contact form built strictly using **HTML5** and **CSS3**. Features a glassmorphism backdrop, smooth neon glow focus effects, custom form controls, and gradient button animations without using any JavaScript.

## 🚀 Live Demo
[Click here to view the Live Form!](https://khushimishra84.github.io/YOUR-REPO-NAME/)

## ✨ Features
* **Glassmorphism Visual Style:** Translucent frosted-glass card design layered over a rich gradient background.
* **Neon Glow Interactivity:** Bright visual feedback when focusing on input fields, select boxes, and textareas.
* **Animated Gradient Button:** Smooth hover effects with multi-color gradient shifting.
* **Comprehensive Inputs:** Includes text fields, dropdown selectors, radio choices, and text areas.
* **Pure HTML & CSS:** Built entirely without external frameworks or JavaScript libraries.

## 🛠️ Built With
* **HTML5:** Semantic form inputs, labels, and structured layout markup.
* **CSS3:** Flexbox, CSS gradients, backdrop filters, transitions, and glow shadows.
